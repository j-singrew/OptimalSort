⚙️ Adaptive Sort Engine: Beating Python's sort()
This repository contains a high-performance, hybrid sorting engine designed to achieve superior performance metrics compared to standard library implementations, specifically targeting the highly optimized Python sort() (Timsort) on large, randomized datasets.

🎯 Project Goal
The primary objective is to implement a robust, professional-grade hybrid sorter, synthesizing techniques from algorithms like Quicksort (3-way), Insertion Sort, and Heapsort (Introspective Sort fallback) to automatically select the optimal sorting strategy based on input array characteristics.
